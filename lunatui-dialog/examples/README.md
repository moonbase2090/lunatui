# `ui_dialog`

Project list built from `lunatui-dialog`, `lunatui-card`, `lunatui-badge` and `lunatui-button`.
`ui_dialog` plays a scripted, non-interactive run: a prompt renames a project as its text is typed,
an alert dialog asks before deleting it, and an alert reports the result. It reads no input
(`--width`, `--height`, `--frames`, `--fps`). `ui_dialog --snapshot` prints one frame as text
(`--tick` picks the frame).
