# lunatui-layout

Layout engine for lunatui: constraints, closed-form solver, solver fallback, `Grid`/`Stack` and memo.

ADR 0002 (`docs/adr/0002-layout-engine.md`) decides the constraint semantics, the closed-form split, and when a layout needs the kasuari fallback. The solver lands in PR 14. This crate is still a stub from the workspace scaffold (PRD §8, PR 01).
