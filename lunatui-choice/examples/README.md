# `ui_choice`

Notification preferences screen built from `lunatui-choice`, `lunatui-button` and `lunatui-card`.
`ui_choice` plays a scripted, non-interactive run: a timer moves focus and flips the choices, and it
reads no input (`--width`, `--height`, `--frames`, `--fps`). `ui_choice --snapshot` prints one frame
as text.
