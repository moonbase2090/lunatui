# Lints and lint expectations

This file has two lists, kept current in every PR:

- **Lint rules (PRD M15):** a mistake found more than once during development (review findings, CI failures, bugs) becomes a lint rule in the same PR or the next one.
- **Lint expectations (PRD M16):** `#[allow]` is not permitted. The only suppression is `#[expect(lint, reason = "...")]`, and every one in the codebase is listed here.
