# lunatui-text

Text for lunatui: borrowed spans, lines and text, measurement, `WrapCache` and `RowSource`.

`wrap` provides word wrapping and [`WrapCache`](src/wrap/cache.rs) row indices (PRD §2.5, roadmap PR 30).

`markdown` (behind the off-by-default `markdown` feature) parses Markdown into a plain syntax tree: `markdown::parse(source, &Options)` returns a `Document` of `Block`s and `Inline`s. It follows `CommonMark` 0.31.2 and can add the GitHub Flavored Markdown tables, strikethrough, task lists, and bare autolinks (`Options::gfm()`). It does no rendering and no I/O, never panics on any input, and parses in time linear in the input size. Tables of Unicode punctuation and HTML entities are generated by `scripts/gen-markdown-tables.py`.
