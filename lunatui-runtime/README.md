# lunatui-runtime

Runtime for lunatui. `Input` reads terminal bytes on a worker thread, decodes parser events, and coalesces available bursts into frames. `Scheduler` drives idle, dirty, and animating frame timing with backpressure (PR 22). `Clock`, `Ease`, `Spring`, and `Tween` provide frame-rate-independent animation primitives (PR 25). With the `app` feature, `App` and `run` wire input, scheduler, grid diff, and session present for interactive examples (PR 23). With the `app` feature, `HitMap` and `FocusManager` support pointer hit-testing and keyboard focus (PR 24).

The off-by-default `image-presenter` feature adds a defaulted `App::render_frame` hook and a runtime-owned Kitty image layer. Existing `App::render` implementations continue to work. An app opts into pixel images by overriding `render_frame`, passing `RenderFrame::parts().2` to `RenderCx::image_sink`, and giving each image a stable nonzero ID and a new generation when its pixels change. Runtime probes the terminal once; unsupported terminals and multiplexer sessions use the Image widget's half-block cell fallback. Prismattyc native, iTerm2, and Sixel presenters are not implemented in this feature yet.
