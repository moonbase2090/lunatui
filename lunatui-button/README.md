# `lunatui-button`

Button and Toggle for lunatui. A [`Button`] is a one-line clickable label in one of five
variants (default, secondary, outline, ghost, destructive) and three sizes, drawn for rest,
focus, pressed and disabled states. A [`Toggle`] is a button that stays pressed. Both take their
colors from `lunatui-ui-tokens`, and `ButtonState` from `lunatui-widgets` turns key and pointer
presses into clicks.
