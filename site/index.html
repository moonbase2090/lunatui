Technical details

Rendering, input, widgets, performance, and build requirements

Rendering

  • 16-byte packed cells
  • Damage-tracked diffing
  • ANSI output encoder writes once per frame
Source: project overview

Input & runtime

  • Keyboard, mouse, and bracketed‑paste input
  • Focus management and hit testing
  • Event-driven frame scheduling with animation
Source: project overview

Widgets & themes

  • Calendar, BigText, and Sparkline widgets
  • Theme tokens and terminal color capabilities
  • Unicode grapheme and width handling
Source: widget crate

Performance method

  • Apple M5 Max · macOS arm64 · release build
  • 240 frames per run; median of five runs
  • Headless counting sink; no terminal latency included
Source: full report

Build requirements

  • Rust 1.88 minimum
  • MIT licensed
  • Install from crates.io with Cargo
Source: package manifest

Testing & CI

  • Built and tested on Linux, macOS, and Windows
  • Allocation tests guard the render hot paths
  • Clippy runs with warnings treated as errors
Source: CI workflow
