Lunatui

Moonlit terminal UIs in Rust

A Rust library for building terminal user interfaces.

Install with Cargo
$ cargo add lunatui

Form

Labels, required markers, dim hints and fail-colored errors around your own inputs.

Name *                                        
         As it appears on invoices            
                                              
Email *                                       
         ✖ Enter a full email address         
                                              
Plan     ○ Free   ○ Pro   ○ Team              
                                              
                                              
Updates  ━━━● Product news                    
                                              
let form = Form::new([
    FormField::new("Name").required().hint("As it appears on invoices"),
    FormField::new("Email").required().error("Enter a full email address"),
    FormField::new("Plan"),
    FormField::new("Updates"),
])
.focus(Some(0));
form.render(area, &mut cx);
RadioGroup::new(["Free", "Pro", "Team"]).flow(RadioFlow::Horizontal).gap(3).render(plan, &mut cx);
Toggle::new(true).label("Product news").render(updates, &mut cx);

ProgressBar

Segmented bars with eighth-block ends, so ok, warn and fail share one track.

checkout                                  done
                                              
compile                                    72%
                                  ████████████
test                                  1 failed
                                             █
upload                                  queued
██████████████████████████████████████████████
ProgressBar::new()
    .segment(0.86, ProgressTone::Ok)
    .segment(0.07, ProgressTone::Warn)
    .segment(0.03, ProgressTone::Fail)
    .render(area, &mut cx);

LogView

A ring buffer of entries, drawn newest first with level colors. It follows new output until you scroll.

14:02:04  WARN /healthz answered in 412 ms (budg
14:02:05  INFO 4 of 6 pods ready                
14:02:05 ERROR connection refused on :9200      
14:02:06  INFO restarting, attempt 2 of 5       
14:02:06  INFO 6 of 6 pods ready                
14:02:06  INFO 1,086 passed, 1 failed           
14:02:06  WARN render::wide_cluster failed on wi
14:02:06  INFO waiting for test stage           
14:02:06 DEBUG rotated 3 tls sessions           
14:02:06  INFO traffic shifted 25%              
let mut log = LogBuffer::new(500);
log.push(LogEntry::new(LogLevel::Warn, "probe", "/healthz slow, 412 ms").stamp("14:02:04"));
log.push(LogEntry::new(LogLevel::Error, "search", "search refused :9200").stamp("14:02:05"));

LogView::new(&log)
    .target_width(0)
    .follow(true)
    .render(area, &mut cx);

BarChart

Vertical or horizontal bars with eighth-block tops, value labels and group gaps.

                                              
                                              
                                              
                                              
                                              
                                              
                                              
                                              
                                              
Mon   Tue   Wed   Thu   Fri   Sat   Sun       
let bars = [
    Bar::new(34).label("Mon"), Bar::new(41).label("Tue"), Bar::new(38).label("Wed"),
    Bar::new(52).label("Thu"), Bar::new(61).label("Fri"), Bar::new(18).label("Sat"),
    Bar::new(12).label("Sun"),
];
BarChart::from_bars(&bars)
    .bar_width(4)
    .bar_gap(2)
    .render(area, &mut cx);

Accordion

Collapsible sections with a caret, a title and a dim badge. Your content goes in each open body.

▾ Build                                2 steps
                                              
                                              
▸ Package                              2 steps
▾ Publish                               1 step
                                              
▸ Notify                                   off
Accordion::new(vec![
    AccordionSection::new("Build", 2).open(true).badge("2 steps"),
    AccordionSection::new("Package", 2).badge("2 steps"),
    AccordionSection::new("Publish", 1).open(true).badge("1 step"),
    AccordionSection::new("Notify", 0).badge("off"),
])
.focus(Some(2))
.render(area, &mut cx);

Technical details

Rendering, input, widgets, performance and build requirements, each with its source.

Rendering

  • 16-byte packed cells
  • Damage-tracked diffing
  • ANSI output encoder writes once per frame
Source: project overview

Input & runtime

  • Keyboard, mouse, and bracketed‑paste input
  • Focus management and hit testing
  • Event-driven frame scheduling with animation
Source: project overview

Widgets & themes

  • Calendar, BigText, and Sparkline widgets
  • Theme tokens and terminal color capabilities
  • Unicode grapheme and width handling
Source: widget crate

Performance method

  • Apple M5 Max · macOS arm64 · release build
  • 240 frames per run; median of five runs
  • Headless counting sink; no terminal latency included
Source: full report

Build requirements

  • Rust 1.88 minimum
  • MIT licensed
  • Install from crates.io with Cargo
Source: package manifest

Testing & CI

  • Built and tested on Linux, macOS, and Windows
  • Allocation tests guard the render hot paths
  • Clippy runs with warnings treated as errors
Source: CI workflow
